# studio/originali · cosa caricare

Qui carichi tu i file originali. Claude Code non li cancella e non li modifica: lavora su copie (CLAUDE.md §1).
Questa cartella non va online e non entra nel build.

## Come caricare dal sito di GitHub
1. Apri il repository e scegli il branch **lavoro** (menu in alto a sinistra, non main).
2. Entra in `studio/originali/` e poi nella cartella giusta.
3. Add file → Upload files → trascina i file → «Commit directly to the lavoro branch» → Commit changes.

## Le cartelle

| Cartella | Cosa ci va | Formato |
|---|---|---|
| `logo/` | Il logo di Biodomus, se ne esiste uno. Oggi la pagina usa un wordmark tipografico. | SVG, oppure PNG trasparente largo almeno 1000 px |
| `foto/` | Foto delle case finite e dei cantieri dell'impresa partner (P1). **Solo con l'autorizzazione scritta** in `documenti/`. Una sottocartella per casa, con il nome della realizzazione (es. `villa-mary/`). | JPG o HEIC originali, alla massima risoluzione |
| `loghi-partner/` | Loghi delle aziende partner. **Solo con l'autorizzazione scritta.** Un file per azienda, con il suo nome. | SVG, oppure PNG trasparente |
| `documenti/` | Autorizzazioni scritte dei partner a usare nome, logo e foto; schede tecniche del sistema costruttivo; APE o documenti che confermano tempi, classe energetica e garanzie. | PDF |

## Da ricordare
- Nessuna foto con persone riconoscibili, targhe o numeri civici senza consenso.
- Le coordinate GPS nelle foto vengono tolte prima della pubblicazione (CLAUDE.md §10.10), ma gli originali qui restano come li carichi.
- Senza autorizzazione scritta una foto resta qui: in pagina vanno le illustrazioni (CLAUDE.md §5).
